# Introduction

`@cloflin/vitepress-theme` is a VitePress theme for documentation sites that want motion with restraint: a sidebar whose ruler stretches under the pointer, a table of contents whose thumb follows the sections on screen, a command-menu search and a theme switch that reveals the new appearance in a circle from the click.

## Philosophy

Every animation answers a question the reader has. The sidebar answers "where am I", the table of contents answers "how far through am I", and the search answers "where is it". Nothing moves for its own sake. Animations are on by default; set `themeConfig.motion` to `'system'` to follow the reader's OS setting, or to `'off'` to keep the page still.

## What is in the box

- A full layout: navbar, sidebar, article, table of contents, mobile menu.
- Local search in a command menu, opened with <kbd>⌘K</kbd> or <kbd>/</kbd>.
- A light and a dark palette, switched with <kbd>D</kbd>.
- Markdown styling for code blocks, code groups, callouts and tables.
